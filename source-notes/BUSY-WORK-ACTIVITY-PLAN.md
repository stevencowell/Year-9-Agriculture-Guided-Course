# Busy Work activity plan

The course-owned `busy-work/` destination contains 21 authentic activities, 63 answerable tasks and more than eight named mechanic families. Every named module topic has a mapped activity; some distinct evidence pathways retain separate activities.

Every activity:

- traces to a taught 2026 topic;
- requires a response rather than a passive view;
- gives immediate checked feedback;
- preserves source and teacher-control boundaries;
- autosaves on the current browser/device;
- supports Print / Save PDF;
- is practice, not automatic submission.

Activity content never quizzes outcomes, codes, assessment administration, teacher metadata or file/folder trivia.
