This static page contains no student records and cannot receive progress events. Names, classes, progress and timestamps are personal information and must not be placed behind a GitHub Pages password.

Static password deliberately not implemented. It would be visible in the published site code and would provide only a convenience gate, not access control.

Approved access model

  1. Enter from the discreet Teacher Dashboard link on the Industrial Arts Main Page.
  2. Sign in once with an approved school Google account.
  3. The server verifies the school account and an explicit teacher allow-list.
  4. Choose a subject or course card.
  5. View only the records permitted for that teacher.

Minimum configuration needed

  • a school-approved server-side storage service and Australian/department-approved data location;
  • school Google OAuth configured by an authorised administrator;
  • server-side verification of account issuer, school domain and an explicit teacher allow-list;
  • separate student write and teacher read permissions;
  • a fixed record schema limited to name, class, course, module, section, progress and timestamp;
  • privacy notice, approval owner, retention period, secure deletion and access-correction process;
  • audit logging, rate limiting, backups and a tested incident-response contact.

No magic link or second email confirmation is planned unless the approved provider requires it.
